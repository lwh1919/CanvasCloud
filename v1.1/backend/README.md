# AI云图库

基于AI技术的企业级图库系统，支持图片上传、URL上传、以图搜图、多维筛选、相似颜色筛选、AI扩展/分析图片、图片分享及团队空间协作编辑。配备完整管理员功能，实现系统级管控。

## 核心功能

- **智能上传**：本地图片上传和URL远程抓取
- **AI搜索**：以图搜图、多维度智能筛选
- **色彩分析**：相似颜色精准匹配
- **AI增强**：图片扩展、智能分析
- **协作空间**：团队共享与权限管理

## 管理员功能

- **用户管理**：创建、删除、更新用户信息，分页查询用户列表
- **权限管控**：系统级权限配置，角色分配
- **全局监控**：空间分析、数据统计
- **系统配置**：全局参数设置与维护
